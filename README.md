# 📊 Matplotlib Line Graph Visualizer

## 📌 Description
This project demonstrates a simple yet elegant 
line graph using Python's Matplotlib library. 
It visualizes a linear relationship between 
X and Y data points with styled markers and 
bold axis labels.

## 🛠️ Technologies Used
- Python 3.x
- Matplotlib

## 📦 Installation
To run this project, install the required library:

pip install matplotlib

## ▶️ How to Run
python ex1.py

## 📈 Output
A clean line graph with:
- Red square markers (rs-)
- Bold X and Y axis labels
- Custom figure size (3.5 x 3 inch)
- Legend support
